# Screenshots

Screenshots must be **real captures of the running app**. None are included yet because they can only be taken on a
computer running the dashboard (Windows is the target).

Capture these after `streamlit run app.py` and save them here with these names:

| File name | What to capture |
|---|---|
| `01_home.png` | Dashboard before starting |
| `02_simulator_normal.png` | Lab simulator, scenario 1, showing the SIMULATED banner |
| `03_simulator_router_unreachable.png` | Scenario 2 |
| `04_simulator_dns_failure.png` | Scenario 3 |
| `05_simulator_packet_loss.png` | Scenario 4 |
| `06_simulator_congestion.png` | Scenario 5 and the "Normal vs busy link" tab |
| `07_simulator_inconclusive.png` | Scenario 6a or 6b with suggested additional tests |
| `08_live_measurement.png` | A real live run on your own network |
| `09_report_download.png` | The Download Report buttons or the opened HTML report |

Tip (Windows): press `Win + Shift + S`, select the area, and paste into Paint to save as PNG.
After adding the images you can link them from `README.md`.
